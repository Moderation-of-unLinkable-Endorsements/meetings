## Notes

### Success criteria (draft)

- Web API available experimentally in Firefox and Chrome, through Nightly, Canary, an experiment, or an origin trial. Support cross-partition endorsement and moderator flows.
- One or more moderators deployed and integrated with sites using PACT for access-control decisions.
- One or more anchors deployed, integrated with credential-issuing moderators and sites using those credentials. Aim for a sufficient pool of anchors, including anchors used by multiple moderators.
- Metrics demonstrating meaningful improvements:
  - Moderators: low abuse rates for clients presenting valid PACT tokens.
  - Browsers: reduced CAPTCHA friction, measured through telemetry such as fewer interactive CAPTCHAs, more automatic solves, and less time solving challenges.
